# V4 static + trained ML — submissions and feedback

This folder tracks v4 LIVE CSV editions and website feedback. Upload only the CSV file. Models make decisions without LLM judgment in edition 001.

The identical root-level copy under `submission/` is available for direct selection in the website upload dialog. The edition record under `version-4/editions/` identifies input, fitted-model and submission hashes, full LIVE coverage and validation.

Local TRAIN temporal validation is reported under `version-4/training-results/`; it is not a LIVE website score. See `version-4/TRAIN_EXECUTION.md` for the fixed split, training sampling, model roles and limitations.
